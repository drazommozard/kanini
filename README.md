# MedCare Pharmacy E-Commerce Website

A full-stack pharmacy storefront built with Python, Django, HTML/CSS, and SQLite.

## Prerequisites
- **Python 3.10+** installed on Windows (ensure **"Add Python to PATH"** is checked during installation).

## How to Run (One-Click Setup)
1. Download or clone this repository and extract the folder.
2. Double-click **`start_pharmacy.bat`**.
3. Wait a few seconds for dependencies to install—your browser will automatically open at `http://127.0.0.1:8000/`.
